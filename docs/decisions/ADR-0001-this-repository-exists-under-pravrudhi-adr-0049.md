# ADR-0001 — This repository exists, governed by Pravrudhi ADR-0049

Status: **accepted (agent-for-operator, 2026-09-11)**

## Context

This repository is the product edition of Pravrudhi, created per [ADR-0049](https://github.com/AxisMeru/pravrudhi/blob/main/docs/decisions/ADR-0049-three-altitudes-studio-product-artifact.md) in the main `AxisMeru/pravrudhi` repository.

ADR-0049 establishes three altitudes:
1. **Studio** (`AxisMeru/pravrudhi`) — Improves the engine
2. **Product** (`AxisMeru/pravrudhi-app`, this repo) — A clean-slate platform users install
3. **Artifact** (e.g., `AxisMeru/prabhasa-nyaya`) — The outcome of one user objective

## Decision

This repository is the product altitude. It:
- Packages the Pravrudhi engine as a versioned wheel dependency, installed from GitHub releases
- Provides its own minimal, product-only interface (no Studio pages: appetite, inbox, candidates, swarm, diffs, heartbeat, trace, parity, search, system, requests, machines, tour, desktop)
- Builds desktop installers for Linux, macOS, and Windows
- Assumes a clean-slate user who installs Pravrudhi, states one objective, and creates one artifact repository

Governance is inherited from the main Pravrudhi repository: the same kernel and spec rules apply. Commits follow the house identity rule: `SharathSPhD <qbz506@york.ac.uk>`, no `Co-Authored-By` trailer.

## Consequences

- The engine version is pinned in `engine/ENGINE_VERSION` and managed by `scripts/install-engine.sh`
- The product interface is independent of the Studio's pages: additions to the product do not require approval from the engine-improvement loop
- Each artifact generated by Pravrudhi lives in its own repository, governed by its own rules
- This repository has no CI/CD dependency on the main Pravrudhi repository; the product fetches the engine wheel from public releases
